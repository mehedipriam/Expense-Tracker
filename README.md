# 💸 SpendWise - Personal Expense Tracker

SpendWise is a full-stack personal finance tracker that helps users manage income, expenses, budgets, and financial goals.

Built using Spring Boot, MongoDB Atlas, and Vanilla JavaScript.

---

## ✨ Features

- JWT Authentication & Authorization
- Add / Edit / Delete Transactions
- Income & Expense Tracking
- Budget Management
- Dashboard Analytics & Charts
- Advanced Filtering & Pagination
- Recurring Transactions
- CSV Export
- Responsive Dark UI

---

## 🛠 Tech Stack

### Backend
- Java 17
- Spring Boot
- Spring Security
- MongoDB Atlas
- JWT Authentication
- Maven

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
